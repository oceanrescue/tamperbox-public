# Contributing to the backlog

Choose the closest [issue form](https://github.com/oceanrescue/tamperbox-public/issues/new/choose), and keep each issue focused on one problem or request.

## Bug reports

Include the affected tool or URL, steps to reproduce, what you expected, and what actually happened. For website issues, include your browser and operating system. For API or MCP issues, include the client and version when available. A small, sanitized input is more useful than a large log dump.

## Feature requests

Describe the task you are trying to complete, what makes it difficult today, and how the change would help. Include your current workaround and alternatives if you have them. You do not need to design the implementation.

## Documentation and questions

Link to the relevant page and identify the confusing, missing, or incorrect information. For a question, describe what you have tried and where you got stuck.

## Follow-up

Check for maintainer questions and add new findings to the existing issue. Keep discussion respectful and focused on the problem. Avoid posting secrets or personal information in issues, comments, attachments, or screenshots.

Pull requests that improve these reporting templates and guides are welcome. Discuss larger changes in an issue first.
