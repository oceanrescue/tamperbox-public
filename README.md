# Tamperbox feedback and requests

This is the public issue tracker for [Tamperbox](https://tamperbox.dev). Use it to report a bug, request a feature or new tool, ask a question, or point out a documentation problem.

[Open an issue](https://github.com/oceanrescue/tamperbox-public/issues/new/choose) · [Browse existing issues](https://github.com/oceanrescue/tamperbox-public/issues) · [Read the documentation](https://docs.tamperbox.dev)

## Before you open an issue

1. Search the [existing issues](https://github.com/oceanrescue/tamperbox-public/issues). If one already covers your problem or idea, add relevant details or a 👍 reaction there.
2. Choose the closest issue form and keep the issue focused on one problem or request.
3. Include the smallest example that explains or reproduces the problem. For bugs, describe what you expected and what happened instead.

Everything posted in this repository is public. Remove credentials, tokens, private URLs, personal data, and confidential content from examples, logs, screenshots, and attachments.

For website and documentation bugs, you can attach an export from Fairlead Recorder. [About Recorder](https://fairleadhq.com/platform/recorder/) · [Recorder documentation](https://fairleadhq.com/docs/recorder/) · [Chrome Web Store](https://chromewebstore.google.com/detail/fairlead-recorder/opieeaanlhoonobnghfobgobonfjjoaa)

Recorded steps, console output, and network requests can help us reproduce a problem, but a recording is optional. For a typo or broken link, the page URL and a short description are enough. Review every exported file for sensitive data before attaching it.

See [CONTRIBUTING.md](CONTRIBUTING.md) for guidance on each type of report.

## What happens next

New issues start in triage. Maintainers may ask for more information, add an issue to the backlog, or mark work as in progress. Closed issues include an explanation or a link to the resolution.

An accepted request is not a delivery-date commitment. Priorities may change as we learn more about the problem.

This repository contains the public backlog and its reporting templates. Tamperbox application changes are maintained separately.
