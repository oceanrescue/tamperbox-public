# Tamperbox public backlog

Report bugs, request features, suggest new tools, and help improve [Tamperbox](https://tamperbox.dev).

[Open an issue](https://github.com/oceanrescue/tamperbox-public/issues/new/choose) · [Browse the backlog](https://github.com/oceanrescue/tamperbox-public/issues) · [Read the docs](https://docs.tamperbox.dev)

## What belongs here

- Bugs in the website, tools, API, MCP integration, or documentation.
- Feature requests and ideas for new tools.
- Incorrect results, confusing explanations, and broken links.
- Questions about using Tamperbox.

Search existing issues first. If someone has reported the same problem or idea, add useful details or a 👍 reaction to that issue.

## How the backlog works

New issues start with `status:triage`. Maintainers may request more information (`status:needs-info`), accept work into the backlog (`status:planned`), or mark work underway (`status:in-progress`). Closed issues include an explanation or a link to the resolution.

An accepted request is not a delivery-date commitment. Priorities can change as we learn more about the problem.

## Sharing examples

Use the smallest example that reproduces the problem. Remove credentials, tokens, private URLs, personal data, and confidential content from logs and screenshots before posting: everything in this repository is public.

See [CONTRIBUTING.md](CONTRIBUTING.md) for reporting tips. This repository hosts the public backlog and its reporting templates; application changes are maintained separately.
